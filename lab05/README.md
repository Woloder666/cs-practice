# Lab05 — работа с файлами и табличными записями

## Запуск

Из корня репозитория:

```sh
python3 lab05/main.py
```

Ввести `events.csv`. Результат:

```text
14
4
2.5
```

Для `events-small.csv` результат: `3`, `2`, `2.0` на отдельных строках.
Каждый запуск перезаписывает `lab05/summary.csv` по выбранной таблице.
В репозитории сохранена сводка по полной таблице.

## Как работает решение

1. `read_rows` перебирает строки обычным `for`. `strip()` убирает пробелы
   и перевод строки по краям. Пустую строку пропускаем через `continue`.
   `split(",")` делит строку на поля, затем убираем пробелы вокруг каждого поля.
   Первую непустую строку сохраняем как заголовок. Для остальных строк сравниваем
   число полей с числом колонок. Если они совпадают, создаём словарь:
   название колонки становится ключом, соответствующее поле — значением.
   Словарь добавляем в список. Значения пока остаются строками.
2. `count_types` создаёт словарь счётчиков. Для нового типа ставим ноль,
   затем увеличиваем его счётчик на единицу. Считаем записи, поэтому запись
   с нечисловыми минутами тоже учитывается.
3. `total_minutes` выбирает записи нужного типа. Заменяет запятую на точку
   и переводит минуты в число через `float`. Если число получить нельзя,
   возникает `ValueError`: `except` перехватывает его и пропускает значение.
   Округляем всю сумму один раз, в конце, через `round(total, 1)`.
   Начальная сумма `0.0` обеспечивает правильный результат при отсутствии записей.
4. `to_csv` начинает текст с заголовка. `sorted(counts)` возвращает ключи
   словаря по алфавиту. Для каждого ключа добавляем тип, запятую, количество
   и `\n` — перевод строки. Даже пустая сводка содержит заголовок.
5. `main.py` получает имя файла через `input`, читает таблицу, вызывает функции,
   печатает три результата и записывает сводку. `len(rows)` — число записей,
   `len(counts)` — число разных типов. Формат `:.1f` печатает ровно один знак
   после точки, например `2.0`.

## Что объяснить на защите

- CSV — текст: первая строка задаёт названия колонок, следующие содержат записи.
  Здесь разделитель — запятая. Модуль `csv` не используется.
- Список хранит все записи, словарь одной записи связывает колонку и значение.
  Например: `{"дата": "2026-03-01", "тип": "ошибка", "минуты": "0.4"}`.
- В полной таблице 15 строк после заголовка, но одна — `битая строка`.
  Она пропущена, поэтому записей 14. Типов 4, минут ошибок:
  `0.4 + 0.6 + 1.0 + 0.5 = 2.5`.
- `with` автоматически закрывает файл, в том числе при исключении.
  `encoding="utf-8"` явно задаёт кодировку для русских букв.
- Режим `"w"` создаёт файл или перезаписывает его, `"a"` дописывает в конец.
- `Path(__file__).parent` даёт папку программы. Поэтому таблица с введённым
  именем и сводка находятся в `lab05`, даже при запуске из корня репозитория.
  Оператор `/` у `Path` соединяет папку и имя файла.
- `if __name__ == "__main__"` запускает ввод и вывод только при прямом запуске.
  При импорте функции можно проверять отдельно, без ввода с клавиатуры.
- Аннотация `lines: list[str]` описывает ожидаемые данные, но не запрещает
  передать открытый файл. Перебор `for` работает с обоими вариантами.
- Запятая как десятичный разделитель обрабатывается в `total_minutes`, если
  значение уже находится в словаре. В исходной строке лишняя запятая создаёт
  лишнее поле, и такая строка пропускается по условию. Кавычки CSV не разбираем:
  в задании требуется простое разделение по запятым.

## Проверка

```sh
python3 -B lab05/test_lab05.py
```

Проверяются пустой ввод, пробелы, короткие и длинные строки, перебор файла
и итератора, счётчики, десятичная запятая, нечисловые минуты, округление,
отсутствующий тип и точный текст сводки.
