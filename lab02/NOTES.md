# Git

## Состояния Git

Рабочая папка — место, где находятся файлы проекта и где мы их изменяем.

Индекс — область, в которую добавляются изменения, подготовленные для следующего коммита.

Коммит — сохранённое состояние проекта в истории Git.
## Git и GitHub

Git — система контроля версий, которая хранит историю изменений проекта.

GitHub — сервис для хранения Git-репозиториев и совместной работы.
